Version: 2026-07-27.4

Welcome to Aether. Aether is an open-source visual-novel runtime and local media management tool. It can read visual novels, local videos, and external subtitles that you import. Please read this document carefully, especially the sections about risk, liability, and intellectual property.

If you are a minor, review this document with a parent or guardian and obtain their permission before use. By selecting “Agree and Continue,” you confirm that you have read, understood, and accepted this document. If you disagree, select “Decline” and stop using the app.

1. Privacy Policy

1.1 Data processed by the app

Aether does not require an account and contains no advertising, user tracking, or developer-operated analytics service. To provide local library, runtime, and playback features, the app processes or stores the following information locally on your device:

- Games, videos, subtitles, cover images, and related files that you select or copy into the app’s directory.
- File paths, display names, cover references, recent-use timestamps, accumulated play time, and video playback positions.
- Language, interface, rendering, compatibility, and diagnostic preferences.
- Saves, caches, and temporary files required for operation.
- Local logs, performance data, error context, screenshots, or diagnostic archives created when diagnostic features are enabled. Diagnostics may include file names, paths, game titles, rendering information, and error context. Review them before sharing.

1.2 Use of data

This information is used only on your device to display your library, run compatible content, restore settings and playback positions, preserve game progress, troubleshoot errors, and improve local operation. The developer does not proactively upload your imported games, videos, subtitles, saves, logs, or other personal files to a developer server.

1.3 Network access and external content

The core library and local playback functions can operate offline. However, imported game scripts, media, or external links may request network resources, and compatibility interfaces may attempt network access when instructed by imported content. These requests are initiated by content you choose to run and do not mean that the Aether developer is collecting data. Import only content you trust. You are responsible for data charges and for the privacy practices of external services.

1.4 Sharing

The developer does not proactively sell or share your local data. Data leaves your device only when you choose to share, copy, or export files or diagnostics. The recipient you select handles that data under its own privacy practices.

Open-source components used by Aether perform parsing, decoding, rendering, and runtime work locally. The developer does not use those components to proactively transmit your content to their authors.

1.5 File permissions and local security

On iOS, Aether reads content that you place in its Files app directory. On other platforms, it reads relevant locations after you import files or grant the corresponding file permission. Core functionality does not require Contacts, Location, Camera, Microphone, or advertising-tracking access.

iOS file sharing may allow the app directory to be accessed through the Files app or a trusted computer. Protect your device, backups, and exported files. Do not run unknown, modified, or potentially malicious content.

1.6 Retention and deletion

Data remains on your device until you delete the corresponding files, remove library records, clear app data, or uninstall the app. Removing a library record may not delete the original file; delete original files through the Files app or a file manager. Copies, backups, and files shared elsewhere are not automatically deleted when the app is uninstalled. Because the developer does not maintain a user-data server, there is normally no developer-held server copy to delete.

To stop using the app or withdraw your decision to use it, stop use and uninstall it. System file permissions can be revoked in device settings.
